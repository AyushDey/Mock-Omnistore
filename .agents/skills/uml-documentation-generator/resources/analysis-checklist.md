# Analysis Checklist

## Technology

- Language identified
- Framework indicators identified
- Build files identified
- Dependency files identified
- Deployment files identified

## Architecture

- Components identified
- Controllers identified
- Services identified
- Repositories identified
- Modules identified
- API routes identified
- External systems identified where possible

## Data

- Database schemas identified
- ORM models identified
- Entities identified
- Relationships identified

## Incremental Analysis

- File hashes generated
- Added files detected
- Modified files detected
- Removed files detected
- Unchanged files reused from cache
- Delta report generated

## Documentation

- Architecture overview generated
- System overview generated
- Component documentation generated
- API documentation generated
- Architecture review generated
- README architecture section updated

## Diagrams

- Component diagram generated
- Class diagram generated
- Sequence diagram generated
- ER diagram generated
